# ربط كاميرات Hikvision و NVR

## 1. روابط RTSP

النظام بيبني رابط القناة لوحده من قسم `nvr` في `config.yaml`:

```
rtsp://USER:PASS@NVR_IP:554/Streaming/Channels/<رقم القناة><01 أو 02>
```

| القناة | Main stream (دقة كاملة) | Sub stream (دقة قليلة) |
|---|---|---|
| 1 | `/Streaming/Channels/101` | `/Streaming/Channels/102` |
| 2 | `/Streaming/Channels/201` | `/Streaming/Channels/202` |
| 12 | `/Streaming/Channels/1201` | `/Streaming/Channels/1202` |

- **استخدم الـ main stream للكاميرات اللي بتقرا لوحات.** الـ sub stream دقته غالبًا 640×360، واللوحة فيه بتبقى صغيرة جدًا على الـ OCR.
- لو كلمة السر فيها رموز زي `@` أو `:` مفيش مشكلة، النظام بيعملها encode لوحده.
- لو مش عايز تمر على الـ NVR، تقدر تكلم الكاميرا مباشرة بـ `source: rtsp://user:pass@CAMERA_IP:554/Streaming/Channels/101`.

## 2. اكتشاف القنوات الشغالة

```bash
python -m lpr scan-nvr --channels 16
python -m lpr probe          # بيحفظ صورة من كل كاميرا في data/probe/
```

## 3. إعدادات الـ NVR

1. **اعمل يوزر مخصوص** للنظام (مثلًا `lpr`) بصلاحية مشاهدة مباشرة (Live View) بس. متستخدمش `admin`.
2. اتأكد إن RTSP شغال: *Configuration → Network → Advanced → Integration Protocol* (في بعض الموديلات)، والبورت 554 في *Network → Port*.
3. لو في مشكلة في الدخول: خلي *RTSP Authentication* على `digest` أو `digest/basic`.

## 4. إعدادات الكاميرا علشان اللوحة تتقري (أهم حاجة)

| الإعداد | القيمة المقترحة | السبب |
|---|---|---|
| Resolution | 1080p أو أعلى | اللوحة محتاجة عرض 130 بكسل على الأقل |
| Codec | H.264 | أخف في فك الضغط من H.265 على الـ CPU |
| H.264+ / H.265+ (Smart Codec) | **Off** | بيبوّظ تفاصيل العربيات اللي بتتحرك |
| Frame rate | 15–25 | |
| Shutter | 1/500 – 1/1000 (ولو في وضع Plate/Road 1/1000) | يمنع الـ blur للعربيات المتحركة |
| WDR | On لو في نور شمس قوي ورا العربيات | |
| IR بالليل | Smart IR أو تقليل الشدة | اللوحة العاكسة بتبيض من الـ IR القوي |

**مكان التركيب:**
- زاوية الكاميرا على اللوحة أقل من 30 درجة أفقيًا ورأسيًا.
- مسافة 5–15 متر، بزووم بحيث عرض اللوحة يبقى من 130 لـ 250 بكسل.
- الكاميرات الواسعة اللي بتصور الشارع كله **مش هتقرا اللوحات كويس**. لو عندك كاميرات 4MP عادية، حط واحدة على مدخل أو حارة بعينها وظبطها على اللوحات.
- كاميرات Hikvision **ANPR/LPR** (اللي بتقرا اللوحات لوحدها) بتدي أحسن نتيجة.

## 5. ضبط منطقة القراية (ROI)

حدد في `roi` الجزء من الصورة اللي العربية بتبقى فيه قريبة واللوحة كبيرة. كده بنتجاهل العربيات البعيدة، وبنقلل الشغل على الجهاز. الـ ROI بيظهر كمستطيل برتقاني في البث المباشر.
